## Development scenario:
Building a simple website - Build a simple business website with text, images, and contact forms


## Environment Planning: Research and plan:

1. IDE: Visual Studio Code (VS Code)  
VS Code is suitable for this project because it supports HTML, CSS, and JavaScript. It also provides additional features such as syntax highlighting, code completion, debugging, and extensions. It is also lightweight and free, making it appropriate for a small web development project.

2. Additional tools would be needed:   

- Github: to have a shared location for project files and makes collaboration easier.
- Git: to track code history, allowing collaborators to work on the project without losing previous versions.
- Web browsers: to test and preview the website.
- Terminal: to use git command.
- Language: HTML, JavaScript, CSS.

3. Hardware requirements  

The project does not require high-end hardware because VS Code and additional tools mentioned above are quite lightweight. HTML, CSS or JavaScript is also lightweight.

- Processor: modern dual core or multiple would be better
- RAM: at least 8GB
- Storage: SSDs
- Internet connection
- Input devices (keyboard), output devices (monitor)

4. Team collaboration   
Our team will use GitHub for collaboration. The GitHub repository will contain the shared project files. Team would need a  communication app (Whatsapp) to communicate and planning.

5. Estimated setup time and complexity  
20-40 minutes for setting up  
20-30 mins for researching  
Complexity: Medium (for beginner programmers)

## Setup Guide Creation : step-by-step setup checklist

1. Confirm that the computer meets the recommended hardware requirements.
2. Download and install Git
3. Download and set up VS Code
4. Download and set up web browsers (Edge, Firefox)
5. Sign up and create a repository on GitHub and add all team members as collaborators
6. Create a new folder on your computer named "Basic web"
7. Initialize a repository in the "Basic web" folder and set the remote origin to GitHub
8. Team members cloned the repository
9. Verify all applications and authorization is working properly
